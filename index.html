Análisis de correspondencia

Contenido ya estudiado Contenido nuevo y función
HTML semántico, enlaces, imágenes, tablas, clases e identificadores Etiquetas ARIA y navegación accesible: describen controles y facilitan el uso con teclado y lectores de pantalla.
Colores, tipografía, márgenes, padding, bordes y diseño responsive básico Variables CSS, grid y media queries: centralizan la paleta y adaptan las tarjetas a distintos tamaños de pantalla.
Enlaces y estructura de documentos HTML JavaScript vanilla y eventos: actualizan búsqueda, filtros, ordenamiento, paginación y carrito sin recargar.
Formularios y contenido organizado en secciones localStorage: conserva el carrito del usuario entre visitas al navegador.
